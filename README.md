# AutomatedDetectionOfCyberAggressionAndAbuserProfiling
•	Designed and developed a real-time chat application with integrated cyber-aggression detection using WebSocket technology to analyze and block harmful messages instantly.
•	Implemented an NLP-based model using Logistic Regression and TF-IDF to classify messages as normal or abusive.
•	Designed an abuser profiling system to track user behavior and restrict repeat offenders. Built secure chat features including friend requests, real-time alerts, and message interception.
•	Technologies Used: Python, MySQL, HTML, CSS, JavaScript, Socket.IO
